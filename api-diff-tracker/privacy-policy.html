Privacy Policy – API Diff Tracker

Last updated: 2026-04-02

1. Overview

API Diff Tracker is a browser developer tool that intercepts network requests (fetch / XMLHttpRequest) on the current tab and displays real-time diffs of API responses inside the Chrome Side Panel. It is designed exclusively for web developers who need to debug or compare API behaviour during local development and testing.

2. Data Collected

While the extension is active on a tab, it may capture the following data solely within your browser:

  • Request URLs and query parameters of JSON API calls
  • HTTP request and response headers
  • JSON response bodies
  • Cookie key-value pairs visible to the page (document.cookie), used for debugging display only
  • Response timing information (duration in milliseconds)

This data may contain personal information if the websites you visit include such data in their API responses.

3. How Data Is Stored

  • All captured data is stored locally in your browser only using chrome.storage.session (cleared when the browser session ends) and chrome.storage.local (stores only UI preferences: saved URL patterns, pinned fields, bookmarks).
  • No data is ever transmitted to any external server, third party, or developer of this extension.

4. Data Retention and Deletion

  • Session data (captured API calls) is automatically erased when the browser session ends.
  • You can manually clear all captured data at any time by clicking the Clear button in the Side Panel.
  • Uninstalling the extension removes all locally stored data.

5. Permissions Justification

  • <all_urls> host permission: Required to inject the network interceptor into any website the developer chooses to debug. The extension does not activate automatically and only captures data while the Side Panel is open.
  • Content script in MAIN world: The interceptor must run in the page's JavaScript context to wrap window.fetch and XMLHttpRequest. This is technically impossible from the isolated extension context.
  • storage: Used exclusively to persist UI preferences locally.
  • sidePanel: Required to display the diff UI in Chrome's Side Panel.
  • tabs: Required to open the Side Panel for the active tab.

6. Children's Privacy

This extension is a developer tool intended for adults. It is not directed at children under 13.

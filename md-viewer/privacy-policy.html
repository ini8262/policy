Privacy Policy – MD Viewer

Last updated: 2026-04-04

1. Overview

MD Viewer is a Chrome Extension that automatically renders Markdown (.md) files as styled HTML in the browser. It is a read-only viewer — it does not edit, upload, or transmit any content.

2. Data Collected

MD Viewer does not collect, store, or transmit any personal data.

The extension reads the raw text content of .md files displayed in your browser tab solely to render them as HTML. This processing happens entirely within your browser and is never sent anywhere.

The only data stored locally is your UI preferences:

  • Theme preference (light / dark) — saved in localStorage
  • Full-width preference — saved in localStorage
  • Checkbox states of task lists — saved in localStorage, keyed by file URL

These preferences are stored only in your browser and are never transmitted externally.

3. Permissions Justification

  • file://*, http://*/*, https://*/* host permissions: Required to inject the content script that detects .md file URLs and renders them. Markdown files can be served from any origin (local filesystem, GitHub, GitLab, private servers). The content script only activates when the URL path ends with .md and the document is plain text — it does nothing on regular web pages.

4. No External Network Requests

MD Viewer makes no external network requests. All libraries (marked.js, highlight.js, DOMPurify, Mermaid) are bundled within the extension and loaded locally. No CDN, analytics, or telemetry is used.

5. Children's Privacy

This extension does not collect any data from anyone, including children.

6. Changes to This Policy

Any updates to this policy will be reflected on this page with a revised date.
